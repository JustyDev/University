# Основы автоматизированного проектирования

ИТС-123, осень 2026. Девять лабораторных работ описывают один программный продукт —
тему ВКР **«Разработка интеллектуального сервиса для перевода и изучения иностранных
языков»** (сервис TransLark, https://translark.ru).

| [2](lab2) | Техническое задание | ГОСТ 34.602-2020, ГОСТ 19.201-78 |
| [3](lab3) | Эскизный проект: архитектура, декомпозиция, схемы алгоритмов | ГОСТ 19.105-78, 19.404-79, 19.701-90 |

| [6](lab6) | Руководство программиста | ГОСТ 19.504-79 |
| [7](lab7) | Руководство пользователя | ГОСТ Р ИСО 9127-94 |
