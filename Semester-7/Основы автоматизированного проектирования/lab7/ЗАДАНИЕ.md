# Лабораторная работа № 7

```
Лабораторная работа № 7. Пользовательская документация. 
 
Задание:  
Ознакомиться с процедурой составления пользовательской (эксплутационной) 
документации к программному продукту согласно ГОСТ Р ИСО 9127-94 «Системы 
обработки информации. Документация пользователя и информация на упаковке для 
потребительских программных пакетов». 
 
 
Оформить документацию согласно требованиям стандарта Р ИСО 9127-94 для своего 
информационного/программного продукта, который планируется реализовать в качестве 
Выпускной Квалификационной Работы (ВКР) в итоге обучения. ```
