# Задание 2. Доработка конфигурации «Склад»

Источник: [Moodle](https://edu.rguk.ru/mod/assign/view.php?id=531704)

Воспроизвести конфигурацию «Склад», а также:
1) создать подсистемы;
2) в отчётах дополнительно сделать отбор по цвету и стране с необязательностью выбора;
3) в расходный документ добавить итоговое количество по аналогии с приходным документом.
