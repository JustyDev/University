# Задание 9. Перенос товаров между группами с отбором по стране

Процедура `ПереносИзОднойГруппыВДругуюНаСервере(ГруппаИсточник, ГруппаПриемник, Страна)`.

Ключевое требование задания — отбор по стране должен быть **в запросе**, а не при
обходе результата:

```sql
ВЫБРАТЬ
    Товары.Ссылка КАК Ссылка
ИЗ
    Справочник.Товары КАК Товары
ГДЕ
    Товары.Родитель = &ГруппаИсточник
    И НЕ Товары.ЭтоГруппа
    И Товары.СтранаТовара = &Страна
```

Так база возвращает только нужные товары, и цикл не тратится на отсев лишних.
Условие `НЕ Товары.ЭтоГруппа` заодно исключает перенос вложенных групп.

На форме появились два поля: «Группа-приёмник» (выбор только групп) и
«Страна для отбора». Обработка сообщает, сколько товаров перенесено, и отдельно
предупреждает, если под условие не попал ни один товар.
