# Задание 3. Обработка «Сервисные операции»: замена цвета и страны по категории

Добавлена обработка `СервисныеОперации` с двумя командами. Обе серверные
процедуры принимают категорию товаров параметром и обрабатывают только её.

## Как решено ограничение «нельзя указать элемент»

Реквизит формы `КатегорияТоваров` имеет тип `СправочникСсылка.Товары`, а у поля
ввода выставлено `ChoiceFoldersAndItems = Folders` (в конфигураторе — «Выбор групп
и элементов: Группы»). Пользователь физически не может выбрать товар, только группу.

Дополнительно в цикле обхода стоит защита `Если ВыборкаТоваров.ЭтоГруппа Тогда
Продолжить`, чтобы вложенные группы не обрабатывались как товары.

## Код

`ЗаменаЦветаНаСервере(Категория)` и `ЗаменаСтраныНаСервере(Категория)` —
директива `&НаСервереБезКонтекста`: процедурам не нужен контекст формы, поэтому
на сервер не передаётся разметка формы и значения её реквизитов.

Выборка ограничивается категорией штатным способом:
`Справочники.Товары.Выбрать(Категория)` — первый параметр метода `Выбрать` это
родитель, то есть перебираются только товары внутри выбранной группы.

Если в категории ничего не подошло, обработка сообщает об этом явно, а не
завершается молча.
