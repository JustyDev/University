# Задание 3. Доработка конфигурации «Склад» (обработка)

Источник: [Moodle](https://edu.rguk.ru/mod/assign/view.php?id=531705)

1) В процедуру «замена цвета» добавить возможность выбора желаемой категории товаров,
   для которых нужно заменить цвет. При этом нельзя давать возможность указать элемент (товар).
2) В процедуру «замена страны» добавить возможность выбора желаемой категории товаров,
   для которых нужно заменить страну. При этом нельзя давать возможность указать элемент (товар).
