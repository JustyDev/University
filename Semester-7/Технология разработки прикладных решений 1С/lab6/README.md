# Задание 6. Выгрузка и загрузка документа через текстовый файл

Формат файла построчный, с типом записи в первой позиции:

```
H;<склад>
R;<товар>;<цвет>;<страна>;<количество>
```

Строка `H` — шапка документа, строки `R` — табличная часть. Такой формат
позволяет прочитать файл одним проходом и не зависит от порядка строк.

## 1) `ВыгрузитьДокументНаСервере()`

Обходит `СписокТоваров` выгружаемого документа и пишет по строке на каждую
позицию. Количество выводится через `Формат(..., "ЧГ=0")`, иначе в строку
попадают неразрывные пробелы-разделители групп разрядов и файл не читается обратно.

## 2) `ЗагрузитьДокументНаСервере()`

Создаёт новый документ `ПриходТоваров`, заполняет склад из строки `H`
и добавляет строки табличной части из строк `R`, находя ссылки по наименованию.
Документ записывается без проведения (`РежимЗаписиДокумента.Запись`) — проведение
остаётся решением пользователя. Функция возвращает ссылку на созданный документ,
и форма сразу подставляет её в поле «Документ прихода».
