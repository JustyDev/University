# Задание 1. Конфигурация «Экскурсии»

Базовая конфигурация воспроизведена по лабораторной работе № 5 сборника 1С:
справочники «Клиенты» и «Экскурсии», перечисление «СпособОплаты»,
документы «Бронь» и «ПосещениеЭкскурсии» (второй вводится на основании первого),
отчёт по доходам на СКД.

Добавлен справочник `Регионы` и реквизит `Регион` у экскурсии — без него
пункты 2 и 4 задания не имеют смысла, региона в исходной конфигурации нет.

## 1) Отчёт «Самая доходная экскурсия» (гистограмма)

Отчёт `СамаяДоходнаяЭкскурсия` — форма с элементом «Диаграмма» типа
«Гистограмма». Запрос группирует проведённые посещения по экскурсии, суммирует
доход и сортирует по убыванию, поэтому самая доходная экскурсия — первый столбец.
Диаграмма заполняется в `ПриСозданииНаСервере`, так что результат виден сразу
при открытии; кнопка «Сформировать» пересобирает его после ввода новых документов.

Вариант на схеме компоновки здесь не годится: структура настроек с диаграммой
(`StructureItemChart`) на платформе 8.3.23 разворачивается компоновщиком в
детальные записи и падает с ошибкой «Детальные записи в диаграмме не допустимы».
Остальные отчёты конфигурации остались на СКД.

## 2) и 4) Колонка «Регион» в списках документов

Для обоих документов созданы формы списка. Колонка добавлена полем с путём
к данным `Список.Экскурсия.Регион` — динамический список позволяет обращаться
к реквизитам через точку, отдельный реквизит документа заводить не нужно.

Для «Брони» набор колонок: дата, номер, клиент, экскурсия, регион.
Для «Посещения экскурсии» — те же плюс сумма и способ оплаты.

## 3) «Отчёт по доходам 2» оформлен как положено

В исходном варианте отчёт — плоский список детальных записей. Здесь:

- группировка по экскурсии, внутри — детальные записи по клиентам;
- ресурс «Сумма» суммируется по каждой группировке и в целом по отчёту;
- сортировка по убыванию суммы;
- отбор по региону вынесен в пользовательские настройки и не обязателен.

Условие «только проведённые документы» задано в запросе (`ГДЕ ПосещениеЭкскурсии.Проведен`),
иначе в доходы попадали бы черновики. Из-за этого условия у обоих документов
разрешено проведение (`Проведение = Разрешить`): при запрете проведения реквизит
`Проведен` всегда ложь и отчёт выходит пустым. Движений документы не делают —
проведение здесь только признак того, что запись состоялась.
