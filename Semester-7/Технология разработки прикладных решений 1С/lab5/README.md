# Задание 5. Загрузка из текстового файла: цвет, страна и защита от дублей

## 1) Импорт цвета и страны

`ЗагрузитьТекстНаСервере()` разбирает строку `Код;Наименование;Цвет;Страна`
через `СтрРазделить(Строка, ";", Истина)`. Цвет и страна — ссылочные типы,
поэтому строковые значения превращаются в элементы справочников функциями
`ПолучитьИлиСоздатьЦвет()` и `ПолучитьИлиСоздатьСтрану()`: если такого элемента
нет, он создаётся, иначе берётся существующий. Файл, выгруженный заданием 4,
загружается обратно без потерь.

Строки короче двух полей пропускаются с сообщением, а не роняют обработку.

## 2) Не загружать одинаковые товары

В базовом варианте из пособия дубли ищутся перебором всей категории для каждой
строки файла — это O(строк × товаров). Здесь проверка вынесена в запрос
`ТоварУжеЕсть()` с условием по родителю и наименованию: база отвечает по индексу,
перебора нет.

В конце обработка сообщает, сколько товаров загружено и сколько дублей пропущено.
