# Конфигурация «Простой склад» — структура по пособию Семёнова (часть 1)

Источник: «Разработка на платформе 1С:Предприятие 8.3. Часть 1», Семёнов А.А., 2023.
Платформа: 1С:Предприятие 8.3.23.1688 (учебная версия), режим совместимости 8.3.23,
схема выгрузки XML — version 2.16.

## Конфигурация
- Имя: `ПростойСклад`, Синоним: «Простой склад»
- Основной режим запуска: Управляемое приложение
- Язык: Русский (ru)

## Справочники

### ЦветаТоваров
- Синоним «Цвета товаров», представление объекта «Цвет», представление списка «Цвета товаров»
- Иерархия: нет
- Длина кода 9 (строка), длина наименования 40, основное представление — в виде наименования
- Автонумерация + контроль уникальности, серии кодов во всём справочнике
- Реквизитов и табличных частей нет

### СтраныТоваров
- Полностью по аналогии с `ЦветаТоваров` (синоним «Страны товаров», представление объекта «Страна»)

### Склады
- Синоним «Склады», представление объекта «Склад», представление списка «Наши склады»
- Иерархия: нет
- Длина кода 9 (строка), длина наименования 25
- Реквизит `АдресСклада` — Строка(100), переменная длина, проверка заполнения «Выдавать ошибку»

### Товары
- Синоним «Товары», представление объекта «Товар», представление списка «Наши товары»
- Иерархия: **есть**, вид «Иерархия групп и элементов», размещать группы сверху
- Длина кода 9 (строка), длина наименования 25
- Реквизиты:
  - `ЦветТовара` — СправочникСсылка.ЦветаТоваров, использование «для элемента», проверка заполнения — не проверять
  - `СтранаТовара` — СправочникСсылка.СтраныТоваров, использование «для элемента», проверка заполнения — выдавать ошибку
  - `Картинка` / `Фото` — картинка товара (на форме есть кнопка «Фото»)
- Форма элемента: нетиповая `ФормаЭлемента`; поле «Родитель» переименовано, заголовок «Категория товаров»

## Регистр накопления

### ОстаткиТоваров
- Синоним «Остатки товаров», вид регистра — **Остатки**
- Измерения: `Товар` (СправочникСсылка.Товары), `Склад` (СправочникСсылка.Склады)
- Ресурс: `Количество` — Число(10,0)
- Регистраторы: ПриходТоваров, РасходТоваров

## Документы

### ПриходТоваров
- Синоним «Приход товаров»
- Реквизит: `Склад` — СправочникСсылка.Склады, проверка заполнения «Выдавать ошибку»
- Табличная часть `СписокТоваров`:
  - `Товар` — СправочникСсылка.Товары, проверка заполнения «Выдавать ошибку»
  - `ЦветТовара` — СправочникСсылка.ЦветаТоваров
  - `СтранаТовара` — СправочникСсылка.СтраныТоваров
  - `Количество` — Число(10,0), неотрицательное, проверка заполнения «Выдавать ошибку»
- Проведение: разрешить, оперативное проведение: разрешить, удаление движений — автоматически при отмене проведения
- Движения: РегистрНакопления.ОстаткиТоваров, тип движения **Приход**
- Модуль объекта:

```bsl
Процедура ОбработкаПроведения(Отказ, Режим)
    // регистр ОстаткиТоваров Приход
    Движения.ОстаткиТоваров.Записывать = Истина;
    Для Каждого ТекСтрокаСписокТоваров Из СписокТоваров Цикл
        Движение = Движения.ОстаткиТоваров.Добавить();
        Движение.ВидДвижения = ВидДвиженияНакопления.Приход;
        Движение.Период = Дата;
        Движение.Товар = ТекСтрокаСписокТоваров.Товар;
        Движение.Склад = Склад;
        Движение.Количество = ТекСтрокаСписокТоваров.Количество;
    КонецЦикла;
КонецПроцедуры
```

- Форма документа: нетиповая `ФормаДокумента`.
  Важно: у полей табличной части «Цвет товара» и «Страна товара» **ПутьКДанным**
  указывается как `Объект.СписокТоваров.Товар.ЦветТовара` (и `...Товар.СтранаТовара`),
  чтобы значения подтягивались из карточки товара автоматически.

### РасходТоваров
- Синоним «Расход товаров»
- Реквизиты и табличная часть — как у `ПриходТоваров`
- Движения: РегистрНакопления.ОстаткиТоваров, тип движения **Расход**, с контролем остатков

## Отчёты

### ОтчетОстаткиТоваров

## Тестовые данные из пособия
- Склады: «Склад основной» (Москва, ул. Строительная, д.1), «Склад дополнительный» (Тверь, ул. Садовая, д.2)
- Группы товаров: «Бытовая техника», «Для сада и огорода»
- Товары: «Чайник (3 л)» (Стальной, Россия), «Грабли садовые» (Зелёный, Россия), «Краска половая (5 л)» (Красный, Китай)

## РасходТоваров — модуль объекта (с контролем остатков)

```bsl
Процедура ОбработкаПроведения(Отказ, Режим)
    // регистр ОстаткиТоваров Расход
    Движения.ОстаткиТоваров.Записывать = Истина;
    Для Каждого ТекСтрокаСписокТоваров Из СписокТоваров Цикл
        Движение = Движения.ОстаткиТоваров.Добавить();
        Движение.ВидДвижения = ВидДвиженияНакопления.Расход;
        Движение.Период = Дата;
        Движение.Склад = Склад;
        Движение.Товар = ТекСтрокаСписокТоваров.Товар;
        Движение.Количество = ТекСтрокаСписокТоваров.Количество;
    КонецЦикла;
    Движения.Записать();

    Запрос = Новый Запрос;
    Запрос.Текст =
        "ВЫБРАТЬ
        |   ОстаткиТоваровОстатки.Товар,
        |   ОстаткиТоваровОстатки.КоличествоОстаток
        |ИЗ
        |   РегистрНакопления.ОстаткиТоваров.Остатки КАК ОстаткиТоваровОстатки
        |ГДЕ
        |   ОстаткиТоваровОстатки.КоличествоОстаток < 0";

    РезультатЗапроса = Запрос.Выполнить();

    Если НЕ РезультатЗапроса.Пустой() Тогда
        Отказ = Истина;
        ВыборкаДетальныеЗаписи = РезультатЗапроса.Выбрать();
        Пока ВыборкаДетальныеЗаписи.Следующий() Цикл
            Сообщить("Не хватает кол-ва для товара " + ВыборкаДетальныеЗаписи.Товар +
                ", нужно еще " + ВыборкаДетальныеЗаписи.КоличествоОстаток);
        КонецЦикла;
    КонецЕсли;
КонецПроцедуры
```

## Отчёт ОстаткиТоваров (на СКД, не на макете)

- Имя `ОстаткиТоваров`, синоним «Остатки товаров»
- Основная схема компоновки данных: `ОсновнаяСхемаКомпоновкиДанных`
- Набор данных `НаборДанных1`, автозаполнение, запрос:

```sql
ВЫБРАТЬ
    ОстаткиТоваровОстатки.Товар,
    ОстаткиТоваровОстатки.Склад,
    ОстаткиТоваровОстатки.КоличествoОстаток
ИЗ
    РегистрНакопления.ОстаткиТоваров.Остатки КАК ОстаткиТоваровОстатки
```
(поле ресурса — `КоличествоОстаток`, роль поля «Остатки»; Товар и Склад — роль «Измерение»)

- Ресурсы: `Остатки` = `Сумма(Остатки)`
- Параметры: `Период` (тип Дата)
- Настройки, вариант «Основной»: структура — `<Детальные записи>`
  - Выбранные поля: `Товар.Наименование`, `Товар.ЦветТовара`, `Товар.СтранаТовара`,
    `Склад.Наименование`, `Остатки`
  - Отбор: `Склад` Равно (пользовательская настройка, «Обычный»)

Задание 2 требует довести отчёт до вида «Остатки товаров 2» (рис. 74 пособия):
отборы по складу, цвету и стране вынесены в пользовательские настройки на форму
и **не обязательны** к заполнению.
