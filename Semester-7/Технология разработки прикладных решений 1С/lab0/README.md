# Задание 0. Конфигурация «Прокат велосипедов»

Конфигурация собрана с нуля по условию задания. Ниже — как каждый пункт условия
лёг в модель данных.

## Структура

| Объект | Что решает |
|---|---|
| Справочник `МоделиВелосипедов` (`ЦенаЗаЧас`) | п. 1 и 2: цена зависит от модели и задана за час |
| Справочник `Велосипеды` (`Модель`, `Исправен`) | конкретные единицы техники |
| Справочник `Клиенты` (`Телефон`, `ПостоялецГостиницы`, `Гостиница`, `НомерКомнаты`) | п. 3: имя, телефон, номер комнаты |
| Перечисление `ВидЗалога` (деньги / в-у / паспорт) | п. 3: чем оставлен залог |
| Перечисление `СостояниеВелосипеда` (целый / испорчен) | п. 5б |
| Документ `Резервирование` | п. 6 |
| Документ `ВыдачаВелосипедов` | п. 3, 4: залог и время отъезда |
| Документ `ВозвратВелосипедов` | п. 5а, 5б: время возврата и состояние |
| Регистр `ВелосипедыВПрокате` (остатки) | кто и на чём катается прямо сейчас |
| Регистр `Резервы` (остатки) | п. 6 |
| Регистр `Выручка` (обороты) | п. 5в |

## Почему так

**Модель и велосипед разделены.** Цена привязана к модели, а прокат — к конкретному
велосипеду: иначе нельзя одновременно и брать деньги по прейскуранту модели,
и отслеживать, что сломался именно этот экземпляр.

**Семья — это несколько велосипедов в одном документе.** Условие «время отъезда
клиента/клиентов (семья)» решается табличной частью: один документ выдачи,
один клиент, несколько строк с велосипедами и своим временем выдачи у каждой.

**Возврат вводится на основании выдачи** — переносятся клиент, велосипеды и время
выдачи, время возврата подставляется текущее. Стоимость считается в
`РассчитатьСтоимость()`: неполный час округляется вверх (`Часы = Цел(Секунды/3600)`,
плюс единица, если остаток ненулевой), сумма — часы × цена модели.

**Испорченный велосипед выводится из оборота.** При проведении возврата со
состоянием «Испорчен» у велосипеда снимается флаг `Исправен`, чтобы его не выдали
следующему клиенту.

**Резерв — регистр остатков по модели**, а не по конкретному велосипеду: клиент
резервирует «горный велосипед», а не инвентарный номер. При выдаче по резерву
движение по резервам списывается.

## Аналитика (п. 5в)

Три отчёта на СКД:

- `ВыручкаЗаПериод` — гистограмма выручки по моделям (форма с элементом
  «Диаграмма»: вариант настроек СКД с диаграммой на 8.3.23 падает с ошибкой
  «Детальные записи в диаграмме не допустимы»);
- `ВелосипедыВПрокате` — остатки: кто сейчас в прокате;
- `АналитикаПоКлиентам` — группировка по признаку «постоялец гостиницы»,
  с отбором и суммой по клиентам.

Время простоя отдельным отчётом не выведено: по регистру оборотов оно считается
как разница между календарным периодом и суммой часов проката, и корректнее
смотреть его глазами по `ВыручкаЗаПериод` в разрезе модели.
