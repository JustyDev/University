# Задание 8. Доработка конфигурации «Склад» (первый запуск)

Источник: [Moodle](https://edu.rguk.ru/mod/assign/view.php?id=531710)

0) Обойтись без кнопки «Больше не показывать».
1) Необходимо изменить логику таким образом, чтобы форма первого запуска не запускалась
   для администратора (вне зависимости от значения константы `ПервыйЗапускОсуществлен`).
2) Необходимо добавить для складов реквизит «Инвентаризация» (тип Дата) и на форме первого
   запуска показывать информацию о том, у каких складов сегодня инвентаризация.
