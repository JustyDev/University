# Задание 8. Форма первого запуска

## 0) Без кнопки «Больше не показывать»

Константа `ПервыйЗапускОсуществлен` (тип Булево) выставляется в `Истина` самой
формой в `ПриСозданииНаСервере` — то есть в момент показа. Отдельная кнопка не нужна.

## 1) Форма не открывается для администратора

Модуль управляемого приложения выполняется на клиенте, где нет ни `Константы`,
ни `Метаданные`, ни `ПравоДоступа` — поэтому вся проверка вынесена в общий модуль
`ПервыйЗапускСервер` (Сервер + Вызов сервера):

```bsl
Функция НужноПоказатьФормуПервогоЗапуска() Экспорт
    Если ПравоДоступа("Администрирование", Метаданные) Тогда
        Возврат Ложь;
    КонецЕсли;
    Возврат НЕ Константы.ПервыйЗапускОсуществлен.Получить();
КонецФункции
```

Администратор отсекается **до** проверки константы, то есть независимо от её
значения, как и требует задание.

## 2) Инвентаризация складов

У справочника «Склады» добавлен реквизит `Инвентаризация` типа Дата (состав даты —
только дата, без времени). Форма первого запуска показывает склады, у которых
инвентаризация назначена на сегодня; отбор сделан запросом с
`НАЧАЛОПЕРИОДА(Склады.Инвентаризация, ДЕНЬ) = &Сегодня`, поэтому время в реквизите
не мешает сравнению. Если таких складов нет, выводится соответствующий текст.

## Что ещё есть на форме

Кроме списка складов форма выводит приветствие и меняет заголовок окна на
«Первый запуск» — оба значения проставляются в `ПриСозданииНаСервере`.
