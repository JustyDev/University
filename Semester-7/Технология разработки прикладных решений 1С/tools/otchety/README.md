# Сборка отчётов `отчёт.docx`

Отчёты собираются из тех же исходников, что лежат в репозитории: `ЗАДАНИЕ.md`
и `README.md` каждой лабораторной плюс скриншоты и листинги кода.

```
crop.py    обрезка скриншотов 1С (убирает пустое поле справа и снизу)
md.js      конвертер markdown -> элементы docx (заголовки, таблицы, списки, код)
labs.js    метаданные работ: тема, список скриншотов с подписями, вывод
build.js   сборка: титульный лист -> задание -> ход работы -> скриншоты -> листинги -> вывод
```

## Что нужно

Node.js с пакетом `docx` и Python 3 с `Pillow`:

```bash
npm install docx
pip install pillow
```

## Как собрать

```bash
# 1. скриншоты (снимаются скриптами tools/queue_prep.py и tools/queue_shots.py)
python3 crop.py ../../_build/shots ../../_build/shots-crop

# 2. подготовить исходные тексты: ЗАДАНИЕ.md и README.md каждой лабы
#    складываются плоскими именами labN.zadanie.md / labN.readme.md,
#    листинги кода — в listings.json (см. комментарий в build.js)

# 3. собрать документы
node build.js <каталог с текстами> ../../_build/shots-crop <каталог результата>
```

Результат — `отчёт.docx` в подкаталоге `labN` каталога результата; файлы кладутся
в соответствующие папки заданий.
