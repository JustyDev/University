# Задание 4. Проверка дублей групп, ссылки на удаляемый товар, цвет и страна в выгрузке

## 1) `СоздатьГруппуНаСервере()` — проверка на существующую группу

Перед созданием выполняется `Справочники.Товары.НайтиПоНаименованию(Имя, Истина)`
(второй параметр — точное соответствие). Если найденный элемент не пустой и это
группа, выводится предупреждение и группа **не создаётся**.

## 2) `УдалитьТоварНаСервере()` — где есть ссылки на товар

Используется `НайтиПоСсылкам()`: он возвращает таблицу с колонками
`Ссылка`, `Данные`, `Метаданные`. Обработка выводит объекты построчно —
видно и вид объекта метаданных, и конкретный документ.

Поведение осознанно разное:

- ссылки есть → товар помечается на удаление, физически не удаляется
  (иначе получились бы битые ссылки в проведённых документах);
- ссылок нет → товар удаляется сразу.

## 3) `ВыгрузитьТекстНаСервере()` — добавлены цвет и страна

Формат строки стал `Код;Наименование;Цвет;Страна` вместо `Код;Наименование`.
Путь к файлу вынесен в реквизит формы `ПутьКФайлу` — в пособии он зашит
в код константой, что делает обработку непереносимой между машинами.
