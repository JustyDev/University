# Задание 4. Доработка конфигурации «Склад» (обработка)

Источник: [Moodle](https://edu.rguk.ru/mod/assign/view.php?id=531706)

1) Корректировка процедуры `СоздатьГруппуНаСервере()`. При создании новой группы реализовать
   проверку на существование группы с таким же именем. Если такая уже существует —
   выдавать предупреждение и не создавать.
2) Модифицировать процедуру `УдалитьТоварНаСервере()` таким образом, чтобы выводилась
   информация, в каких документах есть ссылки на удаляемый товар.
3) В код процедуры `ВыгрузитьТекстНаСервере()` добавить цвет и страну.
