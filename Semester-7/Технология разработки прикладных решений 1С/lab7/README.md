# Задание 7. Копирование документа с вопросом о проведении

Команда `КопироватьДокумент` — аналог штатного «Новый документ» (ввод копированием).

## Как задаётся вопрос

В конфигурации отключено использование модальности
(`ModalityUseMode = DontUse`), поэтому синхронный `Вопрос()` использовать нельзя.
Применён асинхронный вариант:

```bsl
Оповещение = Новый ОписаниеОповещения("КопироватьДокументЗавершение", ЭтотОбъект);
ПоказатьВопрос(Оповещение, "Провести созданный документ?", РежимДиалогаВопрос.ДаНет);
```

Ответ приходит в процедуру `КопироватьДокументЗавершение`, которая и вызывает
серверную часть.

## Само копирование

`ДокументСсылка.Скопировать()` создаёт объект-копию со всей табличной частью;
дата проставляется текущая, номер платформа присваивает сама при записи.
В зависимости от ответа документ записывается с `РежимЗаписиДокумента.Проведение`
или `РежимЗаписиДокумента.Запись`.
