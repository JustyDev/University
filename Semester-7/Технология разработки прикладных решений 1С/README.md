# Технология разработки прикладных решений для системы «1С:Предприятие»

ИТС-123 / ИТС-223, осень 2026. Преподаватель — ст. пр. А.М. Козлов.
[Страница курса в Moodle](https://edu.rguk.ru/course/view.php?id=52517)

## Что здесь лежит

```
Материалы/          лекции, учебные пособия, спецификации по конфигурациям
Скриншоты/          снимки работающих конфигураций, вставленные в отчёты
tools/              генераторы XML-исходников конфигураций и скрипты сборки
tools/otchety/      сборщик отчётов «отчёт.docx» (см. tools/otchety/README.md)
lab0 … lab10/       по одной папке на задание:
    ЗАДАНИЕ.md          формулировка из Moodle
    src/                исходники конфигурации в XML (выгрузка Конфигуратора)
    build/*.cf          собранный файл конфигурации
    отчёт.docx          отчёт по работе
```

Конфигурации **описаны кодом** в `tools/` и собираются пакетным режимом
Конфигуратора — в `src/` лежит канонический XML, который 1С выгружает обратно
после загрузки. Поэтому сборка воспроизводится побайтово одинаково на любой машине.

## Как собрать конфигурацию из исходников

Пример для задания 2 (конфигурация «Простой склад»). `$V8` — путь к `1cv8t.exe`
(Windows) или `1cv8` (macOS), `$LAB` — папка задания.

```bash
# 1. создать пустую файловую информационную базу
"$V8" CREATEINFOBASE 'File="/path/to/base";' /DisableStartupDialogs

# 2. загрузить конфигурацию из XML-исходников
"$V8" DESIGNER /F"/path/to/base" /LoadConfigFromFiles "$LAB/src" \
      /DisableStartupDialogs /DisableStartupMessages /Out load.log

# 3. обновить конфигурацию базы данных
"$V8" DESIGNER /F"/path/to/base" /UpdateDBCfg \
      /DisableStartupDialogs /DisableStartupMessages /Out update.log
```

Быстрый вариант — загрузить готовый `.cf` вместо исходников:

```bash
"$V8" DESIGNER /F"/path/to/base" /LoadCfg "$LAB/build/ПростойСклад.cf"
"$V8" DESIGNER /F"/path/to/base" /UpdateDBCfg
```

После этого база открывается в режиме «1С:Предприятие» обычным способом.

## Как пересобрать конфигурацию из генератора

```bash
python3 tools/gen_sklad.py _build/sklad-src   # сгенерировать XML
# далее шаги 1–3 выше, затем /DumpConfigToFiles обратно в lab*/src
```

Генератор пишет минимальный XML — только заданные свойства; всё остальное
платформа достраивает сама при загрузке. Канонический результат получается
командой `/DumpConfigToFiles`.

## Скриншоты для отчётов

Скриншоты в `отчёт.docx` сняты не руками, а тем же пакетным режимом:

1. `tools/gen_demo_base.py` / `tools/gen_demo_any.py` собирают **демонстрационный**
   вариант конфигурации — к исходникам задания добавляется служебный общий модуль
   `ДемоДанные`, общая форма `ДемоОтчет` и разбор `ПараметрЗапуска` в модуле
   управляемого приложения. В сдаваемую конфигурацию (`lab*/src`, `lab*/build`)
   ничего из этого не входит.
2. `tools/queue_prep.py` создаёт базу, наливает демо-данные запуском
   `ENTERPRISE /CЗаполнитьДемоДанные` и возвращает чистую конфигурацию.
3. `tools/queue_shots.py` запускает 1С с параметрами вида
   `/CПоказатьФорму:Справочник.Товары.ФормаСписка`, `/CПоказатьОтчет:ОстаткиТоваров`,
   `/CПоказатьДокумент:ПриходТоваров` и снимает окно через `PrintWindow`
   (окно снимается из памяти, поэтому чужие окна поверх 1С в кадр не попадают).
4. `otchety/crop.py` обрезает пустое поле, `otchety/build.js` собирает docx.

Внешние обработки (`.epf`) для этого не годятся: их запуск 1С сопровождает
модальным предупреждением безопасности, подтвердить которое в пакетном режиме
некому. Код внутри конфигурации такого предупреждения не вызывает.

**Ограничение учебной версии:** сохранение и печать табличного документа
запрещены (`Функции печати и сохранения табличного документа в учебной версии
недоступны`), поэтому результаты отчётов в отчётах приведены скриншотами,
а не выгрузкой в PDF.

## Запуск скриптов сборки на Windows

Пакетные вызовы 1С обёрнуты в PowerShell-шаблоны (`tools/*.ps1.tmpl`). Каждый
скрипт кладётся в `_runner/in`, watchdog `_runner/runner.ps1` его выполняет и
складывает вывод в `_runner/out`. Каталог `_runner/` в репозиторий не входит —
это локальная обвязка, повторять её на другой машине не обязательно: все команды
1С из шаблонов можно выполнить руками.
